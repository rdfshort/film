Download the app (APK)

How to install

  1. Tap Download the app and open the file when it finishes.
  2. If Android asks, allow installs from this browser (Settings, "Install unknown apps").
  3. Tap Install, then open ReelDrama.

If Google Play Protect shows a notice for a new app, choose "Install anyway". Updates install over the old version and keep your account and coins.

iPhone? The app is Android only for now. Use the website instead.
